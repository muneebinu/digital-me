# Muneeb Ur Rehman — Personal Portfolio

Personal portfolio for Muneeb Ur Rehman, a computer science graduate based in Swat, Pakistan.

**Live site:** https://muneebinu.github.io/digital-me/

## Design system

A warm editorial identity built around the supplied palette:

- Deep Slate Teal — `#244855`
- Vibrant Coral Red — `#E64833`
- Warm Terracotta Brown — `#874F41`
- Muted Sage Blue — `#90AEAD`
- Soft Warm Cream — `#FBE9D0`

Typography uses the self-hosted **Hanken Grotesk** for interface and body copy, paired with **Fraunces** for expressive editorial headings.

## Implementation

- Semantic HTML, responsive CSS and vanilla JavaScript; no build step.
- Stylesheet and script are versioned in the HTML to avoid stale browser/CDN caches.
- Local fonts and existing repository images only.
- Responsive project grid with functional category filters.
- Accessible mobile navigation, keyboard support and reduced-motion handling.
- Branded 404 page and SVG favicon.

## Run locally

Clone the repository and open `index.html` in a browser. A local static server is recommended.
